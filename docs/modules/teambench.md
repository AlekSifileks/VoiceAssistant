# Тимбенч

Статус: набросок работает. После обращения читает задачи, бэклог, карточку, комментарии и табель, списывает время и пишет комментарий. Смена статуса, оценка, создание задачи и спринт отвечают «Так ещё не умею».

## Зачем

Тимбенч — основной рабочий инструмент. Эти фразы остаются локальной командой и не уходят в OpenRouter.

## Граница

Делает:

- разбирает фразу, которая уже не совпала с курсором, телеграмом, браузером или закладкой;
- читает и пишет `https://teambench.ru/api` с ключом `TEAMBENCH_API_KEY`;
- помнит последнюю задачу до конца запуска, чтобы «на неё» писало в неё;
- печатает полный список в терминал и произносит одну короткую фразу.

Не делает:

- не открывает Chrome и не кликает по странице;
- не удаляет задачи, комментарии и списания;
- не читает чужой табель;
- не меняет статус, оценку и спринт и не создаёт задачу;
- не отправляет ключ, задачи и комментарии в чат.

## Контракт

Вход: хвост фразы после имени. `teambench::Desk::perform` возвращает `None`, если это не Тимбенч.

Ключ задачи собирается из букв проекта и числа: «тэ бэ шестьдесят два» — это `TB-62`, если такой проект есть. Несколько задач или несколько проектов ничего не записывают. «Мои задачи» — открытые задачи текущего пользователя, без бэклога и без сделанных. Бэклог без имени проекта не угадывается.

Списание понимает «полчаса», «час», «полтора часа», «два часа», «сорок минут». День по умолчанию — сегодня, ещё можно сказать «вчера» и «позавчера». «Время за неделю» — с понедельника по сегодня.

Запись заканчивается «Готово» и короткой фразой. Ошибка — «Не вышло», причина в терминале.

## Где код

| Файл | Что внутри |
| --- | --- |
| `src/teambench.rs` | разбор фразы, запросы, последняя задача |
| `src/main.rs` | вызывает навык до модели смысла |
| `.env` | `TEAMBENCH_API_KEY` |

Публичные точки: `teambench::Desk::from_env`, `teambench::Desk::perform`.

## Решения

- Сначала существующие команды приложений, потом Тимбенч, потом модель смысла. «Спиши час» не открывает Cursor.
- Поиск отдаёт не больше 20 задач. Если пришло 20, фраза говорит, что показаны первые двадцать.
- Ключ в базу и в журнал не пишется.

## Как проверить

Без сети:

```
cargo test --release teambench::
```

Живой микрофон, после строки «тимбенч: ключ есть»:

```
cargo run --release -- --language ru
```

«Лика, мои задачи» называет число открытых задач. «Лика, спиши час на …» появляется в табеле этой задачи.
