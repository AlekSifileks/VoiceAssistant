# Понимание

Статус: набросок работает. Модель смысла поднимается вместе с помощником и выбирает команду, если дословного слова нет.

## Зачем

Узнавать простую задачу своими словами, не выходя в OpenRouter и не придумывая новое действие.

## Граница

Делает:

- один раз поднимает `nlu/intent_server.py` и держит в нём `cointegrated/rubert-tiny2`;
- по запросу выбирает ближайшую подпись из переданного списка и возвращает число похожести;
- после имени, с «пуск» или без него, если слово не команда и не закладка и не совпало по звучанию, сравнивает хвост с примерами команд. При похожести от 0.93 и отрыве от чужой команды от 0.08 выполняет её. «Редактор» ведёт к Cursor. Искажения вроде «Team Banch» к закладке относятся по согласным в модуле команд: модель смысла пишет «Team Banch» и «Тимбенч» слишком далеко. Ниже порога при сказанном «пуск» помощник говорит «не понял». Без «пуск» фраза остаётся чату.

Не делает:

- не слушает микрофон. «Поболтаем» и «хватит» сюда не попадают;
- не отправляет фразу в OpenRouter;
- не выполняет текст модели как команду оболочки. Выполняется только действие из базы.

План — `plan/08-ponimanie.md`.

## Контракт

`intent::Model::start` читает `INTENT_MODEL`, `INTENT_PYTHON`, `INTENT_SCRIPT`. Нет окружения — в терминал пишется `понимание: …`, помощник слушает дальше, команды остаются дословными.

`intent::Model::guess(text, options)` возвращает `Guess { label, score }`. Пустой текст или пустой список — ошибка процесса.

Сеть нужна только при первой загрузке весов.

## Где код

| Файл | Что внутри |
| --- | --- |
| `src/intent.rs` | процесс и `guess` |
| `nlu/intent_server.py` | загрузка модели и сравнение векторов |
| `nlu/requirements.txt` | `sentence-transformers` |
| `src/main.rs` | запуск вместе с голосом и распознаванием |
| `.env` | `INTENT_MODEL` |

Публичные точки: `intent::Config::from_env`, `intent::Model::start`, `intent::Model::guess`, `intent::DEFAULT_MODEL`.

`nlu/.venv` и кэш весов в git не входят.

## Решения

- Модель маленькая и русская. Языковую модель на миллиарды параметров сюда не ставим.
- Rust не считает векторы. Расчёт — отдельный процесс, он живёт до выхода помощника.
- Дословная команда проверяется раньше и модель не вызывается.
- Порог 0.93 и отрыв 0.08. Близкие, но разные команды не выбираются наугад.

## Как проверить

```
python3 -m venv nlu/.venv
nlu/.venv/bin/pip install -r nlu/requirements.txt
cargo run --release -- --language ru
```

В терминале после голоса есть строка «понимание готово». «Имя пуск курсор» и «имя пуск открой курсор» открывают Cursor. «Имя пуск запусти редактор» тоже. «Имя пуск напиши маме» отвечает «не понял». «Имя, поболтаем» по-прежнему открывает чат.
