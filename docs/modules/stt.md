# Речь в текст

Статус: набросок работает. Закрытая фраза превращается в текст локально, строка печатается в терминал.

## Зачем

Слышать, что именно распознал Whisper, до любого диалога. Текст никуда не отправляется.

## Граница

Делает:

- загружает `ggml-large-v3-turbo` один раз и переиспользует состояние между фразами;
- принимает моно `f32` на 16 кГц — это `capture::Phrase::samples`;
- возвращает строку на языке речи и время распознавания;
- отбрасывает пустой результат и несколько известных фраз, которые Whisper дописывает на тишине.

Не делает:

- не открывает микрофон и не решает, где фраза кончилась;
- не читает wav. Файл по-прежнему пишет оболочка приёма. `--file` в `src/main.rs` — только проверка уже записанной фразы;
- не переводит текст;
- не вызывает OpenRouter и не открывает сеть.

Сравнение моделей — в `plan/01-rech-v-tekst.md`. GigaAM v3 в код не подключён.

## Контракт

Вход: срез `f32`, моно, 16000 Гц. Пустой срез даёт `None`.

Выход: `Option<stt::Transcript>`.

- `Some` — непустой текст и сколько заняло `state.full`;
- `None` — тишина, пустые сегменты или фраза из короткого списка галлюцинаций («спасибо за просмотр», «thanks for watching», «продолжение следует», строки про субтитры).

Язык по умолчанию определяется моделью (`auto`). `--language ru` фиксирует русский и отключает определение.

Оболочка вызывает `Engine::transcribe` на `Event::Phrase`, в том же потоке, который читает микрофон. Пока идёт распознавание, новые кадры могут выпасть из канала приёма. Для поочерёдных команд это нормально: следующую фразу говорят после текста.

## Где код

| Файл | Что внутри |
| --- | --- |
| `src/stt.rs` | загрузка модели и `transcribe` |
| `src/main.rs` | путь к модели, печать текста, `--file` |

Публичные точки: `stt::Engine::load`, `stt::Engine::transcribe`, `stt::DEFAULT_MODEL`.

Веса лежат в `models/ggml-large-v3-turbo.bin` и в git не входят. Каталог `models/` в `.gitignore`.

## Решения

- Рантайм — `whisper-rs` 0.16 с Metal. `WhisperContextParameters::default()` включает GPU, потому что фича `metal` включает `_gpu`.
- Декодирование жадное (`best_of = 1`), температура 0, одна фраза — один сегмент. Так короткая команда не ждёт beam search.
- Контекст предыдущей фразы выключен: команды не должны влиять друг на друга.
- Потоки декодера — число ядер, но не больше 8. Энкодер считает Metal.
- Перевод в английский выключен.
- Журнал whisper.cpp уведён в пустые хуки, в терминале остаётся только наш вывод. Фичи `log_backend` нет, поэтому сообщения библиотеки никуда не пишутся.

## Как проверить

Модель должна уже лежать по пути по умолчанию. Готовая запись:

```
cargo run --release -- --file captures/phrase-001.wav
```

Живой микрофон. После паузы в терминале сначала строка про wav, затем `текст (… мс): …`:

```
cargo run --release --
cargo run --release -- --language ru
```

Первый запуск Metal компилирует шейдеры, загрузка модели занимает дольше следующих.
