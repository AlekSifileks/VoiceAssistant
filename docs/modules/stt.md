# Речь в текст

Статус: кода нет. Контракт зафиксирован, чтобы приём голоса не тащил в себя модель.

## Зачем

Превращает одну уже закрытую фразу в текст. Текст потом уйдёт в диалог. Сейчас ни диалога, ни отправки нет.

## Граница

Будет делать:

- принимать `capture::Phrase` (моно, 16 кГц, `f32`);
- возвращать строку текста на языке речи;
- держать модель загруженной между фразами.

Не будет делать:

- не открывать микрофон и не решать, где фраза кончилась;
- не переводить текст на другой язык;
- не вызывать OpenRouter и не открывать сеть;
- не читать wav с диска. Файл пишет только оболочка приёма, для проверки ухом.

Выбор модели и сравнение — в `plan/01-rech-v-tekst.md`. Кратко: Whisper large-v3-turbo через `whisper-rs` и `whisper.cpp` с Metal. GigaAM v3 остаётся вторым прогоном на русской речи, не вторым путём в этом модуле, пока замер не пройден.

## Контракт

Вход: `capture::Phrase`.

Выход, когда модуль появится: текст одной фразы и признак пустого результата (тишина, которую нарезка всё же пропустила). Язык строки не переключается на английский.

Точка расширения уже снаружи модуля приёма: `Event::Phrase` в `src/main.rs`. Распознаватель вешается туда, а не внутрь `src/capture.rs`.

## Где код

Исходников нет. Ожидаемое место — `src/stt.rs`. Оболочка в `src/main.rs` только вызывает его на `Event::Phrase`.

## Решения

- Распознавание локальное. Звук наружу не уходит.
- Режим — готовая фраза, не поток частичных слов.
- Отдельный переводчик не подключается. В будущий диалог уходит текст как его вернул Whisper.
