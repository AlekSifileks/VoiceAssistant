# Документация модулей

Эти файлы — контекст по модулям помощника. Перед правкой модуля читай только его файл и перечисленные в нём исходники. Остальной код открывай, если меняется контракт на границе или документ модуля ему противоречит.

После изменения поведения обнови файл модуля в том же изменении: контракт, файлы, решения. Не копируй сюда большие куски кода.

Общий план и сравнение распознавателей лежат в `plan/`, не здесь.

## Как устроен помощник

```
микрофон → audio-capture → Phrase (моно, 16 кГц, f32)
Phrase → stt → текст
текст ─ «Энни …» → commands → открыть приложение → «Готово» или «Не вышло»
       ├ задача, бэклог, время, комментарий → teambench → API Тимбенча
       ├ «Энни, поболтаем» → chat → OpenRouter → Qwen3-TTS
       └ другая фраза → печать текста
```

Приём, распознавание, команды, понимание и озвучка локальные. Сеть открывает чат после «поболтаем», Тимбенч по своей фразе и первая загрузка локальных весов. Пока ответ звучит, кадры микрофона за эту паузу выбрасываются. Понимание поднимается вместе с помощником. Дословная команда и фраза Тимбенча идут мимо него. Незнакомое слово после «пуск» сравнивается с примерами локально.
