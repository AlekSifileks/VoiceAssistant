# Документация модулей

Эти файлы — контекст по модулям помощника. Перед правкой модуля читай только его файл и перечисленные в нём исходники. Остальной код открывай, если меняется контракт на границе или документ модуля ему противоречит.

После изменения поведения обнови файл модуля в том же изменении: контракт, файлы, решения. Не копируй сюда большие куски кода.

Общий план и сравнение распознавателей лежат в `plan/`, не здесь.

## Как устроен помощник

```
микрофон → audio-capture → Phrase (моно, 16 кГц, f32)
Phrase → stt → текст
текст ─ «Энни пуск …» → commands → открыть приложение → «Готово» или «Не вышло»
       ├ «Энни, поболтаем» → chat → OpenRouter → Qwen3-TTS
       └ другая фраза → печать текста
```

Приём, распознавание, команды и озвучка локальные. Сеть открывает только чат и только после «поболтаем». Пока ответ звучит, кадры микрофона за эту паузу выбрасываются.

## Модули

| Модуль | Файл | Статус |
| --- | --- | --- |
| Приём голоса | [modules/audio-capture.md](modules/audio-capture.md) | набросок, слушает микрофон и режет фразы |
| Речь в текст | [modules/stt.md](modules/stt.md) | набросок, Whisper печатает текст фразы |
| Команды | [modules/commands.md](modules/commands.md) | набросок, «Энни пуск» открывает приложение |
| Голосовой чат | [modules/chat.md](modules/chat.md) | набросок, «поболтаем» ведёт разговор через OpenRouter |
| Озвучка | [modules/tts.md](modules/tts.md) | набросок, чат говорит Qwen3, команда говорит «Готово» |

Окно на Mac — `app/`. Оно запускает этот же бинарник и правит `data/assistant.db`. Сборка: `app/build.sh`.
